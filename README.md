# RIWAAZ — Premium Animated Rakhi Showcase

A responsive React + Vite Rakhi collection display website.

## Features
- 10 local rakhi designs
- Category filters
- Quick-view product modal
- Add to Bag with total price
- **No checkout/payment flow**
- Gentle floating animation on all Rakhi cards
- Rakhi hover highlight + image zoom + quick-view label
- Small reference-style cursor: tiny dot + thin trailing circle
- Scroll reveal animations
- Parallax background typography
- Scroll progress bar
- Animated quotes and festive marquee
- Light/dark theme toggle
- Responsive mobile/tablet/desktop layout

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
